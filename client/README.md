# Library client

React 19 front end for the Library app (Vite, React Router 7, axios). Deployed on Netlify.

See the [project README](../README.md) for setup and commands, and [ENV_SETUP.md](../ENV_SETUP.md) for environment variables.

```
npm run dev     # dev server on http://localhost:3000 (proxies /api to :5000)
npm run build   # production build into build/
npm run preview # serve the production build locally
```
